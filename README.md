# post-it

A simple web application that allows users to create virtual sticky notes on a webpage. You can write text, choose colors for the note and text, and then post them on the page. The notes are draggable.

## Features

- Create new sticky notes with custom text.
- Customize the background color of each note.
- Customize the text color of each note.
- Drag and drop notes to arrange them on the page.
- Change the background color of the entire page.

## How to Use

1.  **Change Page Background:** Click the color input button at the top-right corner of the page and select your desired color.
2.  **Create a Note:**
    *   Enter your text in the text area located at the bottom-right of the page.
    *   Choose a background color for your note using the color picker next to the "Background Color" label.
    *   Choose a text color for your note using the color picker next to the "Text Color" label.
    *   Click the "Post It!" button. A new note will appear on the page.
3.  **Move a Note:** Click and drag any note to position it where you want on the page.
